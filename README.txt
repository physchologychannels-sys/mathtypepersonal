EquationStudio - offline equation worksheet

A) Use it right away, no internet, no hosting
   1. Unzip this folder anywhere (e.g. Documents\EquationStudio).
   2. Double-click index.html. It opens in your browser and works offline.
   3. App-style window (Windows, Chrome): make a shortcut with this target
      "C:\Program Files\Google\Chrome\Application\chrome.exe" --app="file:///C:/Users/YOURNAME/Documents/EquationStudio/index.html"
      (Edge: msedge.exe in C:\Program Files (x86)\Microsoft\Edge\Application\)

B) True install (icon in the address bar, works on phone too)
   Browsers only allow "Install" for pages served from https.
   1. Upload this whole folder to a free host (Netlify Drop: app.netlify.com/drop, GitHub Pages, or Cloudflare Pages).
   2. Open the https link once in Chrome/Edge, click the Install icon in the address bar
      (phone: menu > Add to Home screen). After that it works offline.

Your worksheet is saved in the browser you use. Download the .docx for anything important.
